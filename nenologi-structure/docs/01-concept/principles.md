# Principles

1. Natural-language meaning comes first; formal notation is a representation of meaning, not meaning itself.
2. The engine must distinguish explicit information, logical entailment, plausible inference, ambiguity, unsupported claims and contradictions.
3. Uncertainty must be exposed rather than hidden.
4. Analysis profiles specialize a common semantic core.
5. Comparison is independent of text type.
6. The default user interface should be practical and simple.
7. Formal logic should be available as an advanced view.
8. Results should be reproducible enough to support QA and testing.
9. Nenologi complements grammar, terminology and similarity analysis; it does not replace them.
10. Input-size limits are part of the product design and may vary by analysis profile and mode.
