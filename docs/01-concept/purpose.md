# Purpose

Nenologi adds a logical-semantic analysis layer to conventional text analysis.

Instead of asking only whether two texts look similar or contain the same terminology, Nenologi asks:

- What does the text assert?
- Which entities, properties and relations are established?
- Which quantifiers, conditions, temporal relations and modalities apply?
- What follows from the statements?
- Where is the interpretation ambiguous?
- If two texts are compared, has the logical or semantic structure changed?

The user-facing output should normally be clear natural language. Formal notation is an optional advanced representation.
