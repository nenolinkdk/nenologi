# Analysis profiles

Nenologi uses a shared semantic engine with specialized analysis profiles.

Initial / priority profiles:

- General text
- Biography
- Procedure / recipe
- Technical instructions
- Specifications
- Prompt
- SEO / web content

An analysis profile determines which semantic relations are emphasized and how the result is presented. It does not require a completely separate engine.

Each applicable profile may operate in single-text mode or comparison mode.

Later / experimental profiles are Rules / legal, Argumentation, Historical / news, Literary / poetry, Professional profile / application analysis, and Claim & source consistency analysis.
