# SEO / web content

SEO analysis focuses on semantic clarity rather than keyword counting alone.

Possible checks:

- Intended search/topic intent versus actual page meaning
- Entities and relations
- Service/product/location relationships
- Title, H1, introduction and body consistency
- Visible content versus structured-data meaning
- Internal semantic relationships between pages
- Semantic drift between localized versions

The aim is to identify semantic gaps: concepts may occur on a page without the page clearly establishing the intended relation between them.
