# Copyright and test material

The public repository may contain only material that can legally be redistributed:

- Original synthetic examples
- Verified public-domain material
- Appropriately licensed Creative Commons material whose conditions are satisfied

Every non-synthetic public case must record source, author/publisher when known, URL or stable identifier, license, retrieval date, and any modifications. “Available online” is not evidence of permission.

Private, client, purchased, confidential, personally sensitive, or license-uncertain material must not be committed. Local/private corpora should live outside the repository and be referenced through ignored configuration. Test fixtures should avoid real personal data unless lawful use and redistribution are clearly established.

Before release, review corpus provenance and repository history—not only the current tree—because deleting a file in a later commit does not remove it from earlier history.
