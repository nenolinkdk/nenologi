# Minimum viable product

## Goal

Prove that Nenologi can convert short texts into useful semantic structures and compare two structures consistently.

## MVP profiles

1. General text
2. Translation comparison
3. Prompt / output

## MVP semantic features

Entities, relations, negation, conjunction/disjunction, quantifiers, modality, conditions, temporal relations, numerical thresholds, additions, omissions and contradictions.

## MVP Windows UI

- analysis profile selector
- mode selector
- source/text input
- optional second-text input
- word counter and limit
- Analyze button
- plain-language interpretation
- findings panel
- optional logical representation
- JSON/debug view
- PDF export

The first version is deliberately **not** a full editor.

## Comparison statuses

Equivalent, Minor semantic difference, Possible meaning change, Significant logical difference, Ambiguous / review required.

Severity and confidence must be separate values.
