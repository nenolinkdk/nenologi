# Trawedit integration

Trawedit is intended to be the first client of Nenologi.

Possible workflow:

```text
Trawedit document / aligned segment
        ↓
Nenologi analysis
        ↓
Semantic / Logic QA findings
        ↓
Trawedit side panel
```

Trawedit should normally present simple findings such as:

- Meaning preserved
- Possible meaning change
- Logical difference

Formal analysis should be available as an optional detailed view.
