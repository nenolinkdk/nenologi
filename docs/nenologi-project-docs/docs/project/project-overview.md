# Project overview

## Purpose

Nenologi adds a logical-semantic layer to text analysis.

It asks:
- What does the text actually assert?
- Which entities and relations are established?
- Which conditions, modalities, quantities and temporal relations apply?
- What follows from the represented statements?
- Where is the text ambiguous?
- If two texts are compared, has the semantic or logical structure changed?

## Core principle

Natural language is not reduced blindly to formal logic.

Possible interpretation states:
- explicit
- entailed
- probable
- ambiguous
- unsupported
- contradicted
- cannot be safely formalized

## User experience

Default findings should be practical:
- Meaning preserved
- Possible meaning change
- Logical difference
- Ambiguous
- Requirement weakened
- Sequence changed
- Condition omitted

Formal logic belongs in an optional advanced view.

## Early use cases

Translation QA, Biography, Procedure / recipe, Prompt, Prompt / output, SEO / web content.

## Input limits

Nenologi should enforce configurable word limits. Early prototypes should favor short, testable texts.
